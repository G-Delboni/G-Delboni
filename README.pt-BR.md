# Gabriel Delboni

Desenvolvedor de software no Brasil. Construo sistemas com LLMs: agentes com tool calling, saída estruturada, guardrails e evals. Minha base é backend (Java e Spring Boot, TypeScript, Python), e estudo Cibersegurança na FATEC Americana, o que orienta como trato prompt injection e dados pessoais em agentes.

No trabalho, desenvolvo um agente de atendimento por WhatsApp para um produto multi-tenant (código privado). Os repositórios abaixo são projetos meus.

## Comece por aqui

- **[agente-whatsapp-ia](https://github.com/G-Delboni/agente-whatsapp-ia)**: atendente de WhatsApp sobre a API da Anthropic, em Python e FastAPI. Laço de agente escrito à mão, com ferramentas estritas, cache de prompt, guardas de custo e de dados pessoais, e uma suíte de evals que roda offline no CI. Também extrai notas fiscais e recibos para dados estruturados, com confiança por campo.
- **[nyx](https://github.com/G-Delboni/nyx)**: aplicativo de bandeja para Windows que supervisiona agentes de código, em Tauri 2, Rust e React. Acompanha as sessões por hooks, delega o trabalho em etapas que esperam aprovação humana e fala os avisos. É um MVP em desenvolvimento.
- **[AITaskAssistant](https://github.com/G-Delboni/AITaskAssistant)** (Lume): assistente de produtividade em Java 21, Spring Boot e Spring AI com Google Gemini. O modelo transforma linguagem natural em um comando estruturado; o código Java valida, aplica as regras de negócio e é o único que acessa o banco.
- **[SpringAiFinancial](https://github.com/G-Delboni/SpringAiFinancial)**: assistente de finanças pessoais com tool calling do Spring AI e transcrição de áudio, protegido por chave de API e limitador de requisições.
